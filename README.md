# Wynder — Website

Static site, ready to deploy on Netlify as-is — no build step required.

## Deploy on Netlify (drag-and-drop, ~30 seconds)
1. Go to https://app.netlify.com/drop
2. Drag this entire folder onto the page
3. Netlify gives you a live URL immediately

## Adding a new watch to the site
1. Add photo(s) to `images/` following the naming convention documented
   at the top of `data/listings.js`.
2. Add one entry to the array in `data/listings.js`.
3. Done — it appears in Browse, is filterable, and has a working product
   page at `product.html?id=<id>` immediately.
